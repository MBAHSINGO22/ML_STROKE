## 📖 Deskripsi Proyek

**ML_STROKE** adalah proyek klasifikasi medis berbasis Machine Learning yang bertujuan untuk memprediksi kemungkinan seseorang terkena stroke berdasarkan data klinis seperti usia, hipertensi, kadar glukosa, jenis kelamin, pekerjaan, dan kebiasaan merokok.

---

## 🎯 Tujuan

- Memprediksi risiko stroke pada pasien menggunakan model supervised learning
- Membandingkan performa berbagai algoritma ML: Decision Tree, Random Forest, Logistic Regression
- Visualisasi distribusi dan korelasi data
- Evaluasi model dengan metrik akurasi, precision, recall, dan f1-score

---

## 🧠 Teknologi & Library

- Python 3.10+
- Pandas & NumPy
- Matplotlib / Seaborn
- Scikit-learn
- Jupyter Notebook
